# ファビコン設定 & EN/JA言語切替（デフォルト英語）設計

日付: 2026-06-12
ステータス: ユーザー承認済み

## 目的

1. アプリ固有のファビコンを設定する（現在は Next.js デフォルトの favicon.ico のまま）
2. UIの言語を EN/JA で切替可能にし、デフォルトを英語にする（現在は日本語ハードコード）

## ファビコン

採用デザイン: **案A — クロップツールのグリフ（白）＋インディゴ背景（#6366f1、角丸）**。
アプリの主ボタン（indigo-500）と同系色。16px でもつぶれにくい定番モチーフ。

配置ファイル（Next.js 16 の App Router 規約に従う）:

| ファイル | 役割 |
| --- | --- |
| `app/icon.svg` | メインのファビコン（ベクター、高精細） |
| `app/favicon.ico` | 旧ブラウザ・Safari 向けフォールバック（16/32/48px PNG入りICOに置き換え） |
| `app/apple-icon.png` | iOSホーム画面用 180x180（角丸なし全面塗り） |

静的エクスポート（`output: "export"`）でもこれらはそのまま `out/` に出力される。

## 言語切替

方式: **軽量自作方式**（React Context ＋ 辞書ファイル）。
next-intl 等のライブラリや `/en` `/ja` のURL分割は、1ページの静的アプリには過剰なため不採用。

- すべてのUI文言を `lib/i18n.ts` の辞書（`en` / `ja`）に集約。TypeScript で
  キーの過不足を型チェックする
- `components/LanguageProvider.tsx`（client）が現在言語と辞書を Context で配布。
  `useI18n()` フックで各コンポーネントから利用
- デフォルト言語は **英語**。ユーザーの選択は `localStorage`（キー: `lang`）に保存し、
  次回アクセス時に復元（SSGの初期HTMLは英語のため、ja保存時はハイドレーション後に切替わる。
  軽量ツールとして許容）
- ヘッダー右上に「EN / JA」切替ボタンを設置
- `document.title` と `<html lang>` は言語切替に連動して effect で更新。
  `layout.tsx` の静的メタデータは英語（"Image Crop & Compress"）
- `lib/`（imageProcessor 等）が投げるエラーは言語非依存のエラーキーとし、表示側で
  発生時点の言語に翻訳する。**切替後に過去のエラーメッセージは再翻訳しない**（許容範囲）

## 検証

- `pnpm build`（静的エクスポート）が通ること
- ブラウザで初期表示が英語、EN/JA切替が全文言に効くこと、再読込で言語が保持されること
- タブにファビコンが表示されること
